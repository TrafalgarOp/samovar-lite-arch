# Samovar Lite – Arch Linux Package

Unofficial Arch Linux packaging for [Samovar Lite](https://github.com/AliMilani/samovar-lite), a PotPlayer-style media player for Linux built on libmpv and Qt.

## Installation

Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/samovar-lite-arch.git
cd samovar-lite-arch
```

Build and install the package:

```bash
makepkg -si
```

## Dependencies

The required dependencies are handled by `makepkg` and include:

- Python
- PySide6
- python-mpv
- mpv
